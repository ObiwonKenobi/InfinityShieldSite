A real-time GM activity dashboard for an EQEmu server, run in Docker on Blackout. It tracks GM commands, item grants, kills, player deaths, bot activity, level progression, character status and the Spire audit log through a dark-themed web page.

The second version fixed a duplicate class and race table that was silently shadowing the correct one, added optional token authentication, moved the database password off the command line, added a single-instance lock and a health check for the web process, a Discord alert for new commands, a SQLite history that survives log truncation, and change detection that skips the build when nothing changed, which brings idle CPU near zero. It is released under the MIT license.

Infinity Shield threat brief

A rolling 30 day cybersecurity brief refreshed every Monday, plus a calendar-month archive. Each run researches primary sources, checks the numbers, rebuilds the pages and publishes with no review step, behind validation that refuses to publish on a bad build. It also draws a day by day timeline, a weekly month by month view across the archive, a New this week section, and charts with a text version of every figure. The whole site was passed through an accessibility audit to WCAG 2.1 and 2.2 AA with the dark theme kept.

The agents

  • Weekly threat brief

    Running · Mondays

    Researches the last 30 days of exploited vulnerabilities, breaches, supply chain attacks, outages and law enforcement actions, checks primary sources such as DOJ, CISA and the CERTs, rebuilds the rolling brief on this site and publishes it, with a New this week section showing what changed.

  • Monthly archive

    Running · First of each month

    Once a month closes, researches that month alone and writes it into the archive, which feeds the month by month timeline.

  • Morning brief

    Paused · Daily

    A daily personal summary to start the day. Switched off for now.

  • Heartbeat

    Paused · Several times a day

    Periodic check-ins through the day. Switched off for now.

  • Session tracker

    Running · As sessions finish

    Works through the Security Congress session list: plays each session video, completes the session evaluation, and keeps a spreadsheet of sessions, credits and what is left against the 31 Jan 2027 reporting deadline.
